# MornDesktopTube

ブラウザで再生中のYouTubeをmacOSのデスクトップ背景へ映すアプリ。macOS 14以降、外部ライブラリ不要。

## 起動

ビルドにはXcodeまたはSwiftを含むCommand Line Toolsが必要です。

```sh
zsh build.sh
open dist/MornDesktopTube.app
```

1. 普段使っているブラウザでYouTubeを開き、動画を再生します。
2. メニューバーの再生アイコンを押してダッシュボードを開き、「ウィンドウを選ぶ」からYouTubeのウィンドウを共有します。
3. ダッシュボードの外をクリックして閉じます。音量・表示先・拡大・背景停止も同じダッシュボードで操作できます。

Dockにはアイコンを表示しません。独立した設定ウィンドウは開かず、メニューバーのダッシュボードだけで操作します。

Googleへのログインは普段のブラウザで行います。本アプリはCookie、パスワード、ブラウザのプロファイルを読み取りません。選択したウィンドウの映像をScreenCaptureKitで受け取り、背景のウィンドウへ表示します。録画保存や映像の外部送信は行いません。共有はmacOS標準の選択画面で許可します。

## ログインとPremium

[Googleは埋め込みブラウザからのログインを制限しています](https://support.google.com/accounts/answer/7675428?hl=ja)。このため、アプリ内ブラウザへのログインではなく、既存のブラウザの再生を利用します。

[YouTube Premiumの広告なし再生](https://support.google.com/youtube/answer/6308116?hl=ja)は、Premium契約のあるアカウントでログインしたブラウザ側に適用されます。動画内に組み込まれたスポンサー紹介などは除去されません。本アプリに広告ブロック機能はありません。

## 使うときの注意

- **映すのはウィンドウ全体です。** YouTube専用のウィンドウを用意してください。別のタブに切り替えると、その内容も背景に映ります。
- 動画だけを映すにはYouTubeの全画面表示を使い、元のブラウザとは別のデスクトップ（Space）へ戻ります。ブラウザ・macOSの組み合わせによる挙動は実機で確認してください。
- 元のウィンドウは開いたままにします。他のウィンドウで覆うことはできますが、最小化・終了・ブラウザの省電力機能で映像が止まる場合があります。
- 音声はブラウザから出ます。ダッシュボードの音量バーは**Mac全体の出力音量**を調整し、ほかのアプリにも影響します。バーを動かすと消音を解除します。YouTubeだけの音量・一時停止・動画変更はブラウザで操作してください。「背景を停止」や本アプリの終了ではブラウザの再生は止まりません。
- 音量はダッシュボードを開いている間、毎秒読み直します。HDMIなどMacから音量を変更できない機器では、機器側で調整してください。
- 1つのウィンドウを1台のディスプレイへ表示します。最大1920×1080・30 fpsです。背景へのクリックは透過し、デスクトップのアイコンを操作できます。
- DRMなどで保護された映像は黒く表示される場合があります。
- 再起動後はウィンドウを選び直します。配布用署名・公証・自動起動は含みません。

## 検証

```sh
swift test
zsh build.sh
codesign --verify --deep --strict dist/MornDesktopTube.app
```

テストは背景のウィンドウ階層、クリック透過、Space設定、合成フレームの実描画、音量コマンドの範囲・構文、出力音量の読み取り、ダッシュボードの描画を確認します。プレビューは `.build/dashboard-preview.png` に保存します。macOSのWindowServerが必要です。テストから実際の音量は変更しません。Googleアカウントへのログインや実際のYouTubeの共有操作は自動化しません。

実機では、メニューバーからダッシュボードを開く→ウィンドウ選択→動画の背景表示→ダッシュボードを閉じる→アイコン操作→映像変更→背景停止の順に確認します。Premium適用、動画の全画面表示、Space切り替え、ウィンドウ最小化と復帰はブラウザ側を含めた確認が必要です。
